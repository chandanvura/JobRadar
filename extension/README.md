# JobRadar 1-Click Application Autofill Extension

A lightweight, zero-tracking Manifest V3 browser extension built specifically to eliminate repetitive form-filling across:
- **Greenhouse** (`boards.greenhouse.io`, `job-boards.greenhouse.io`)
- **Lever** (`jobs.lever.co`)
- **Workday** (`*.myworkdayjobs.com`)
- **Ashby** (`jobs.ashbyhq.com`)
- **SmartRecruiters** (`careers.smartrecruiters.com`)

---

## ⚡ How to Install (Takes 30 seconds)

1. Open your Chromium browser (Google Chrome, Microsoft Edge, Brave, Arc, or Opera).
2. Navigate to `chrome://extensions/` (or `edge://extensions/`).
3. Turn on **Developer mode** (toggle in the top-right corner).
4. Click **"Load unpacked"**.
5. Select the `extension/` folder located inside the JobRadar repository (`f:\Dev\JobRadar\extension`).

---

## 🚀 How to Use

1. Click the **JobRadar Autofill** extension icon in your browser toolbar.
2. Fill in your details once:
   - First Name & Last Name
   - Email
   - Phone
   - LinkedIn URL
   - GitHub URL
   - Portfolio / Website URL
3. Navigate to any JobRadar job apply link (e.g. an Anthropic or Apollo.io job posting).
4. Click **"⚡ 1-Click Autofill Form"**!
5. All matching fields are populated instantaneously.

---

## 🔒 100% Client-Side Privacy Guarantee
- All applicant profile data is stored exclusively in your browser's private local storage (`chrome.storage.local`).
- Zero data is transmitted to external servers, analytics trackers, or third parties.
